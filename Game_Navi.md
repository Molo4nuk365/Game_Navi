## Что реализовано в коде (Текущий функционал)

### 1. Боевая система и Счетчик Комбо (Combo Counter)
*   Написан скрипт отслеживания последовательных попаданий по врагу в реальном времени.
*   Реализовано автоматическое накопление множителя комбо при успешных атаках персонажа.

### 2. Изменение атаки Мстислава при Комбо 3х (Усиленный выстрел)
*   Реализован триггер переключения режимов атаки: при достижении счетчика **3х**, скрипт меняет логику дальнего боя.
*   Технически **изменяется тип пульки **.
*   Для визуализации усиленного энерго-заряда подключены кастомные неоновые спецэффекты (пресеты **`arcane_blue`** и **`electric_violet`** (В разработке у Шурале - дальний бой)).

### 3. Скриптовая ликвидация Шурале при Комбо 4х
*   Реализована проверка максимального уровня комбо: при достижении множителя **4х**, на врага отправляется событие фатального урона.
*   Прописан триггер мгновенного уничтожения/смерти для конкретного кибер-противника — **Шурале**.

##  Технический стек
*   **Движок:** Unity 2D
*   **Язык программирования:** C#
*   **Визуальный стиль:** 2D Pixel Art / Cyberpunk
*   **Конвейер графики:** URP (Universal Render Pipeline) для настройки свечения (Bloom) и шейдеров (ShaderLab/HLSL)
*   **Интерфейс:** UI Toolkit (в футуристическом стиле)
*   **Система контроля версий:** Git + GitHub
